# Flarestore

IPA files for the Flarestore source of the Woof apps (WoofMusic, WoofPlay, WoofPhoto).

Each release holds one IPA. `versions.json` lists the published versions; the Woof Cloud Worker turns it into the AltStore / SideStore source.

Do not edit `versions.json` by hand: `scripts/publish-ipa.py` in Woof Cloud updates it.
